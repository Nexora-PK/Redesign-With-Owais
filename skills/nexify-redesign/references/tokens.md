# Nexify Redesign: Production Design Tokens

## 1. Spatial Rhythm Grid (8-Point System)
- `space-1`: 4px (micro padding, icon gaps)
- `space-2`: 8px (compact element spacing, tag margins)
- `space-3`: 12px (form input inner padding)
- `space-4`: 16px (standard card padding, element gaps)
- `space-6`: 24px (group spacing, component margins)
- `space-8`: 32px (container internal separation)
- `space-12`: 48px (section spacing on mobile)
- `space-16`: 64px (major section spacing on desktop)
- `space-24`: 96px (hero section vertical padding)

## 2. Chromatic Scale (Quiet Neutrals)
### Dark Mode:
- Canvas (Background): `#09090b` (`zinc-950`)
- Surface (Card/Sidebar): `#121215`
- Elevated (Modal/Dropdown): `#18181b`
- Border Subtle: `rgba(255, 255, 255, 0.08)`
- Text Primary: `#fafafa` (`zinc-50`)
- Text Secondary: `#a1a1aa` (`zinc-400`)
- Text Muted: `#71717a` (`zinc-500`)

### Light Mode:
- Canvas (Background): `#fafafa` or `#f8fafc`
- Surface (Card/Sidebar): `#ffffff`
- Border Subtle: `rgba(0, 0, 0, 0.08)`
- Text Primary: `#09090b` (`zinc-950`)
- Text Secondary: `#52525b` (`zinc-600`)
- Text Muted: `#a1a1aa` (`zinc-400`)

## 3. Typography Hierarchy
- Hero Headline: `48px` - `60px`, `font-semibold`, `tracking-tight`, `leading-[1.1]`
- Section Title (H2): `32px` - `36px`, `font-semibold`, `tracking-tight`
- Card Title (H3): `18px` - `20px`, `font-medium`, `tracking-tight`
- Body Text: `15px` - `16px`, `font-normal`, `leading-relaxed`
- Captions/Metadata: `13px` - `14px`, `font-normal`, `text-secondary`
