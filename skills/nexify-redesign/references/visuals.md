# Nexify Redesign: Visual Anchors & Focal Moments

A common failure of AI-generated design is lacking a clear visual focal point, or using abstract floating gradient blobs.

## Rules for Focal Moments:
1. **One Bright Element:** Each screen or viewport should have one primary visual anchor that carries color and craft.
2. **Contextual Authenticity:** If it is a SaaS analytics app, the visual should be a rich, interactive data visualization or dashboard frame.
3. **Calm Space for Text:** Never overlay dense text directly over busy, noisy backgrounds.
4. **SVG Vector Precision:** Prefer crisp, lightweight SVG diagrams, charts, and technical illustrations.
