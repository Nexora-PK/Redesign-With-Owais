# Redesign With Owais: AI-Tell Diagnostic Heuristics

Scan code or visual screens against this comprehensive checklist to identify and eliminate prototype artifacts:

| Category | AI-Generated Anti-Pattern | Redesign With Owais Standard |
| :--- | :--- | :--- |
| **Color** | Violet/purple/indigo gradients on cards and text | Tinted zinc/neutral backgrounds with high-contrast solid text |
| **Glows** | Heavy box-shadow glows (`shadow-purple-500/50`) | Subtle, layered ambient shadows (`shadow-sm` or `shadow-md`) |
| **Badges** | `AI Powered` or `Get Started` with emojis | Clean typographic pills: `v2.4`, `Feature`, `Beta` |
| **Type** | `uppercase tracking-widest text-[10px]` | Natural sentence-case text at readable scale (`12px` to `14px`) |
| **Cards** | Cards inside cards with heavy glassmorphism blur | Flat surface grouping separated by 1px subtle borders |
| **Headlines** | Vague corporate buzzwords | Concrete, short, declarative benefit statement |
| **Buttons** | Floating gradient pills with hover bounce | Solid, high-contrast action buttons with crisp borders |
| **Spacing** | Inconsistent arbitrary margins | Strict 8pt grid scale (8px, 16px, 24px, 32px, 48px, 64px) |
| **Images** | Floating 3D glossy spheres or abstract blobs | Concrete product assets, clear UI diagrams, or data visualizations |
